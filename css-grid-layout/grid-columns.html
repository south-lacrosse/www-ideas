Sample of Our Layout With CSS Grid Columns

Saw this way of styling layouts and thought it looked interesting, so tried it for our layout (at least as of 2026) - so we have a 1024px column which is centred, and alignwide content fills this, with default alignment content 720px wide and left justified in that column, with alignfull content the full width.

Our current way uses an .inner container, and then busts out of that for alignfull with negative margins, which works fine, though it does need a bit of margin to handle scrollbars.

This styling is saved here in case we want to use it in the future (we should!) - maybe when we move to a block theme?
